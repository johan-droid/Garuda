# Population Data Source Register

## Source 1: Census of India 2011 Primary Census Abstract (PCA)
- **Publisher:** Office of the Registrar General & Census Commissioner, India (ORGI), Ministry of Home Affairs
- **URL:** https://censusindia.gov.in
- **Licence/Terms:** Government Open Data License - India (GODL)
- **Attribution Required:** "Data Source: Census of India 2011, Office of the Registrar General, India"
- **Access Mode:** download / bulk
- **Format:** CSV / XLSX / JSON
- **Coverage:** State (Odisha), District (Khordha), Sub-districts (Blocks/Tehsils), Towns, and Villages
- **Vintage/Version:** 2011 (Final Population Totals)
- **Status:** VERIFIED
- **Notes:** Definitive reference baseline for population, sex ratio, and literacy. Must be labelled as `historical` vintage (2011) in UI without undisclosed algorithmic projection.
